          Enter a CNIC, mobile number or email

          Sherlocks searches every connected system for that person, draws a record node for each system that knows them, and a person node for everyone those records name. It then searches those people too, until the depth you set.

          Strong link — a system states the relationship (landlord, co-accused, SIM owner…)

          Weak link — inferred: similar address, same father's name, overlapping hotel stay, OSINT. A lead, not evidence.
